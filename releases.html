Release notes

What changed in each version of TotalClean. The newest is at the top.

Version 1.0.1 17 November 2026Latest

  • Usage access and the helper are locked by Android for apps installed from a download. The app now sets out the three steps to unlock them, with a button for each, wherever it asks for either one.

Version 1.0 17 November 2026

  • First public release. Quick Clean with a reason and a safety rating for every category, and a 30-day safety bin.
  • Deep Clean, Sleep Mode and Browser Cleaner through the TotalClean helper.
  • Storage, Apps (with multi-select uninstall and saving install files to Drive), storage map and chat media.
  • Photos: similar sets, bad shots, exact duplicates, swipe review and a Photo Optimiser with a WebP option.
  • Google Drive transfers, checked against the Drive copy before anything is removed.
  • Automatic cleaning with rules, weekly report and low-space warning.
  • Storage forecast, growing apps, device health and security tips.
  • Encrypted vault with fingerprint unlock, private-file finder with Look inside pictures, and an optional app lock.
  • Home screen widget, quick settings tile and your own choice of Home shortcuts.

Checking your download

The file for version 1.0.1 is called TotalClean.apk. It is 23.5 MB (23,465,228 bytes). Its SHA-256 checksum is:

6b476b4b9f5e32fcd4dad8817f8f9940fdfa138aca12dd2446ffb108191c8b64

On Windows, run certutil -hashfile TotalClean.apk SHA256 and compare. Every version is signed with the same key, so each one installs over the last and keeps what you have saved.

Older versions are on the GitHub releases page.
