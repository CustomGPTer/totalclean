What TotalClean does not do

TotalClean has no memory booster and no antivirus. If Android will not let an app reach something, it says so rather than inventing a number. It is not on Google Play, so you install it from this site.

Where the others do more

Files by Google is also a full file manager, shares files offline and is small on the phone. Both are on Google Play and update themselves.
